\# Netflix Content Analysis Dashboard



\## Project Overview

This project analyzes Netflix content trends using Python and Excel.



\## Tools Used

\- Python

\- Pandas

\- NumPy

\- Jupyter Notebook

\- Excel

\- Pivot Tables

\- Pivot Charts



\## Key Analysis

\- Titles Added Over Years

\- Movie vs TV Show Growth

\- Top Countries

\- Top Genres

\- Rating Distribution



\## Key Insights

\- Netflix content peaked in 2019

\- Movies dominate the platform

\- USA contributes highest content

\- International Movies is the top genre

\- TV-MA is the most frequent rating
